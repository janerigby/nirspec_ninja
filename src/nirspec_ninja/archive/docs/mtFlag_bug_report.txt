Subject: JWST NIRSpec moving-target observations incorrectly labeled mtFlag=False

Hello MAST Help Desk,

In the course of a research project, I happened to find some JWST NIRSpec observations whose FITS TARGTYPE indicates they are moving targets,  but the MAST CAOM observation metadata reports mtFlag=False. Consequently, an astroquery.mast query with mtFlag=True systematically omits these files, while mtFlag=False includes them.

Minimal reproduction:

from astroquery.mast import Observations

for root in ["jw01444002001", "jw02416003001", "jw02550013001"]:
    table = Observations.query_criteria(obs_id=f"{root}*")
    print(table[["obs_id", "proposal_id", "mtFlag", "target_name"]])

For example, querying jw01444002001* returns mtFlag=False. In contrast, jw01191009001* returns mtFlag=True, showing that the mtFlag=True query mechanism itself is functioning but classifies a disjoint set of observations.
